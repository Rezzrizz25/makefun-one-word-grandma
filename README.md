The single word Grandma would text about AI: **thingamabob** — the warm,
slightly baffled name a grandma gives a gadget she cannot name. A judge
model compares words two at a time; the funniest, most grandma-like word
wins. The field is crowded with typo jokes (robit, robut, computor,
chatgbt) and the obvious gadget words (thingamajig, doohickey,
contraption, whatchamacallit, newfangled, witchcraft) — thingamabob,
the grandma-iest of them all, was still free.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3, stdlib only) writes exactly one word,
`thingamabob`, to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`),
which the gate checks is UTF-8 text of 1–30 characters. No network,
no dependencies, deterministic: three local runs produced byte-identical
output.
